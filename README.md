# Панель путешественника

Тематический дашборд для организации поездок. Создан на чистом HTML, CSS и JavaScript (ES6 Modules) с использованием принципов ООП (классы, наследование, инкапсуляция).

## Как запустить локально
1. Откройте проект в VS Code.
2. Нажмите правой кнопкой мыши на `index.html` и выберите **"Open with Live Server"**.
*(Важно: из-за использования ES-модулей проект нельзя открывать двойным кликом, нужен локальный сервер).*

## Источники API
В проекте реализовано два виджета с внешними API (без секретных ключей):
1. **Курсы валют** — API Центрального Банка РФ (`https://www.cbr-xml-daily.ru/daily_json.js`).
2. **Цитата дня** — DummyJSON (`https://dummyjson.com/quotes/random`).
*(Виджет погоды использует wttr.in, но при блокировке сети корректно обрабатывает ошибку и показывает демонстрационные данные с кнопкой повтора).*

## Использованная нейросеть
При создании проекта использовалась нейросеть **DeepSeek**.

## Полезные промпты
1. **Каркас и классы:** «Создай базовый класс UIComponent с методами render() и destroy(), а также класс Dashboard для управления виджетами на чистом JS с использованием ES-модулей».
2. **Список дел:** «Создай класс ToDoWidget, наследующий UIComponent. Внутри карточки: поле ввода, кнопка Добавить, список задач. Сохрани данные в localStorage».
3. **Обработка ошибок API:** «Добавь в виджет погоды обработку ошибок сети, таймаут на 3 секунды и кнопку Повторить, которая будет перезапрашивать данные».
